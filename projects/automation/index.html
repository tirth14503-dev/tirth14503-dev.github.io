AI-Automated SC Analytics

Self-Directed Build · Tirthal Kothari

A repeatable workflow from supply chain data to analysis and stakeholder alerts.

The challenge

This self-directed build explored how to connect supply chain data, analysis, and stakeholder alerts in one repeatable workflow.

What I did

I set up a Supabase Postgres warehouse, used Quadratic’s AI spreadsheets for analysis, and connected n8n workflow automation to move supply chain datasets and send Gmail alerts.

The deliverable

An end-to-end pipeline connecting stored data, AI-assisted analysis, and automated email alerts.

Tools & methods

  • n8n
  • PostgreSQL
  • Supabase
  • Quadratic AI
  • Gmail API
